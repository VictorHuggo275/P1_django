# Versões do desenvolvimento

Estas pastas são cópias didáticas de pontos importantes do histórico Git:

- `v01_estrutura`: projeto Django inicial, sem o app de domínio.
- `v05_admin`: entidades criadas e disponíveis no Admin.
- `v08_telas`: views e templates para exibição.
- `v10_comanda_sem_fechamento`: comanda por mesa e itens, ainda sem a rota de fechamento.
- `v11_final`: versão final com fechamento da conta.

O histórico Git real continua disponível na pasta `.git` do projeto principal.
